About this map

Kafka 3.9 → Spark 3.5.3 + Sedona 1.9.1 → GeoParquet → DuckDB 1.5.5 (make export, pure-SQL JSON writer) → MapLibre GL JS 5.9.0, vendored. Sources: MTA Bus Time GTFS-RT; the nycbuspositions archive (2017-2024 historical positions); NOAA AORC; NYC TLC taxi zones.

All data on this page is static JSON under /files/ — the read API is documented in docs/read-api-contract.md.

Rain sources

Insight views: NOAA AORC hourly (analysis), hour-ending. Live view: MRMS RadarOnly QPE 01H, uncalibrated, hour-ending.

The MTA gate

MTA gate: the MTA’s redistribution terms are not verified, so nothing MTA-derived is published here. The gate cuts by LINEAGE and has two sides — vehicle positions (the live fleet, the bus impact overlay) and alert rows (the MTA flood tier) — and both are dark. Those layers still appear, marked GATED: absence should be explained, not mysterious.

Reading the chips

FRESH — inside its source’s staleness budget · STALE — over budget, or no age could be read · OFF — nothing is being fetched · GATED — the MTA gate side is shut; dark, never absent · AGE — age known, no budget frozen, so no verdict is claimed.
