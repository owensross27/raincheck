About this map

Kafka 3.9 → Spark 3.5.3 + Sedona 1.9.1 → GeoParquet → DuckDB 1.5.5 (make export, pure-SQL JSON writer) → MapLibre GL JS 5.9.0, vendored. Rain: NOAA AORC hourly (analysis), MRMS RadarOnly QPE (live). Ground: TLC taxi zones over a vector basemap, one PMTiles archive read by range request.

Sources: MTA Bus Time GTFS-RT; the nycbuspositions archive (the 2017-2024 historical bus positions behind every past-storm number here); NOAA AORC; NYC TLC taxi zones; basemap Protomaps © OpenStreetMap contributors (ODbL).

Every number on this page is read from static JSON under files/; the read surface is documented in docs/read-api-contract.md.

Reading the chips

Each row is one data source and its chip says how current it is; a bare AGE means no staleness budget is frozen for that file. Nothing is fetched until you tick it.

FRESH — inside its frozen staleness budget.

STALE — over budget, or no age could be read; the reason prints.

OFF — nothing is being fetched.

GATED — dark behind a licence gate; the row stays, explained.

AGE — age known, no budget frozen, so no verdict.

One fill at a time: both options colour the same areas with one shared ramp, so they can never disagree on screen.
